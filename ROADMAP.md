# Atlantis Roadmap

## v0.1.x (Current)
- 6-widget Liquid Glass shell: Dynamic Island, 8-box Customizable Top-Left Control Hub, Todo/Calendar, Dock, 2-Card Launcher, Center Clock
- Universal Linux Wayland Compositor Adapter (Hyprland, Sway, Niri, Generic wlroots)
- `App BG: Solid` adaptive backdrop above apps + `Eco` Power Save mode (`0.0%` idle CPU)
- Customizable `font_scale` + `clock.boxes` layout

## v0.2 (Next)
- Native SVG icon rasterization (`resvg`) in Launcher & Dock
- Custom widget plugin API
- Prebuilt Linux `x86_64` & Windows `.exe` GitHub Release binaries
